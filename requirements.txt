# Минимальные зависимости не требуются (всё работает на стандартной библиотеке Python)
# Для работы алгоритмов достаточно Python 3.9+

# Опциональные зависимости (только для разработки и отладки):
# pytest - для запуска тестов проектов
# pytest-timeout - для ограничения времени выполнения тестов
# pytest-cov - для анализа покрытия кода (расширенная версия)

# Для работы с бенчмарками:
# tests4py - современный бенчмарк для Python (опционально)

# Пример установки опциональных зависимостей:
# pip install pytest pytest-timeout
# pip install tests4py

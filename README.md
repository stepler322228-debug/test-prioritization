# Система приоритизации модульных тестов

## Описание

Проект реализует **три алгоритма приоритизации тестов** (Test Case Prioritization, TCP) для оптимизации порядка выполнения модульных тестов. Цель — максимизировать скорость обнаружения дефектов (APFD), запуская наиболее «подозрительные» тесты первыми.

### Методы приоритизации

| Метод | Источник | Суть |
|-------|----------|------|
| **Hill Climbing** | ACM 1830483.1830735 | Локальный поиск оптимального порядка перестановкой тестов |
| **Time Aware** | ACM 1572272.1572297 | Учёт времени выполнения и бюджета времени |
| **History-Based** | IEEE 10011511 | Использование истории падений тестов (частота, давность, серьёзность) |

## Как это работает

1. **Статический анализ** — сканирование директории проекта для поиска всех тестовых файлов (`test_*.py`, `*_test.py`)
2. **Загрузка упавших тестов** — чтение списка упавших тестов из файла `failing_tests.txt`
3. **Приоритизация** — каждый алгоритм вычисляет оптимальный порядок тестов на основе своей стратегии
4. **Вывод метрик** — вывод APFD и топ-10 приоритизированных тестов
